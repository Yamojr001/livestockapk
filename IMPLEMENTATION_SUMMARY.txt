📊 DATA FLOW SUMMARY

ONLINE SUBMISSION:
  Device App → Take Photo → Convert Base64 → Cache Locally 
  → Send Base64 to Backend → Backend Saves to Storage/farmers/ 
  → Backend Returns Image Path → Cache Remote URL 
  → Store Submission with Image Reference

OFFLINE SUBMISSION:
  Device App → Take Photo → Convert Base64 → Cache Locally 
  → Store as Pending Submission → Wait for Internet 
  → Sync: Read Cache → Convert Base64 → Send to Backend 
  → Backend Saves → Cache Remote URL → Update Submission

IMAGE DISPLAY:
  Check Cache Index → Cache Found? 
  → YES: Load from Cache (Fast, Offline-Ready) 
  → NO: Load from Remote URL → Auto-Cache for Later
